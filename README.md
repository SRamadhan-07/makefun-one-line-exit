A Python program — standard library only, no network — that writes one line to /output/entry.txt: a one-line resignation letter whose two weeks' notice is the sentence itself, with the other thirteen days written off as a rounding error. The line is 120 characters, inside the competition's gate of 1 to 140 characters of UTF-8 text, and the file is byte-identical on every run.

## Run it

```sh
python3 main.py
```
